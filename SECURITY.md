# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or exposed
credential. Report it privately to `contact@hackihub.com` with the affected
version, reproduction details, and potential impact.

We will acknowledge receipt, investigate, and coordinate disclosure and a fix
as appropriate. Do not access data that is not yours or disrupt production
services while researching a report.

## Supported versions

Security fixes are provided for the latest published release. Users should
upgrade to the newest signed release before reporting an issue that may already
have been corrected.
